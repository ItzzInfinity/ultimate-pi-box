# MyIP Component

## Scope

- show the current IP address
- refresh network details
- list available Wi-Fi networks
- support Wi-Fi connection flow

## Planned Inputs

- `nmcli` output for network scanning and connection

## Planned UI States

- IP overview
- Wi-Fi network list
- password entry
- connection result message

## Notes

- Password entry should be encoder-driven so the device can be configured without a keyboard.
