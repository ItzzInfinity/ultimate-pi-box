# Connect Phone Component

## Scope

- control music streamed from a connected Bluetooth phone
- read metadata through DBus
- provide previous, play or pause, and next actions

## Planned Inputs

- BlueZ DBus media player interface
- connected Bluetooth device information

## Planned UI States

- connected device status
- track metadata view
- transport controls

## Notes

- This component is for media control of the currently connected phone, not for Bluetooth adapter configuration.
