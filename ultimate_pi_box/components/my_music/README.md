# My Music Component

## Scope

- browse local songs
- play local files through VLC
- show current title on OLED
- support previous, next, pause, repeat, and shuffle

## Planned Inputs

- local files from `v2/data/music/`
- supported extensions such as `mp3`, `wav`, `flac`, `m4a`

## Planned UI States

- library list
- now playing screen
- playback controls

## Notes

- This component should reuse the strongest ideas from the current `local_music.py` prototype.
